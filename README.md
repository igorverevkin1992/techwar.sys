# TECH.WAR v3.4

Autonomous AI video production system for YouTube documentaries. Powered by a **Chain of 8 Agents** architecture — each agent builds on the previous output to produce a complete, bilingual (EN/RU), retention-optimized video script.

## Architecture

```
Scout → Radar → Analyst → Architect → Doc Circle → Act Planning → Outliner → Writer
```

| Agent | Role | Output |
|-------|------|--------|
| **Scout** | Scans global news via Google Search | 4 topic cards with hooks, viral factors, protagonist/antagonist |
| **Radar** | Applies viral methodology to the chosen topic | Narrative angles & video hypotheses |
| **Analyst** | Fact-checks claims via Google Search | Structured research dossier with smoking-gun sources |
| **Architect** | Designs retention structure | Timecoded 6-act investigative map + thumbnail concept |
| **Doc Circle** | Story architecture (Steps 1–3) | Conflict matrix + Global Harmon Circle + 4-act division |
| **Act Planning** | Act deep-dive (Steps 4–5) | Per-act story circles + 16-beat outline |
| **Outliner** | Full treatment | Scene-by-scene numbered outline with setup/payoff arcs |
| **Writer** | Visual scripting | 30+ blocks, EN audio + RU translation, streamed output |

### Models per Agent

| Agents | Model | Reason |
|--------|-------|--------|
| Scout, Radar, Architect, Doc Circle, Outliner | Gemini 3.0 Flash | Speed, high quota |
| Analyst, Act Planning, Writer | Gemini 3.0 Pro | Factual precision, writing quality |
| Image generation | Gemini 2.5 Flash Image | Storyboard frames |

Model assignments can be overridden per-agent in the Settings panel.

## Key Features

### Pipeline Execution
- **Steppable Mode** — pipeline pauses between agents; each output is editable before proceeding
- **Full Auto Run** — runs all 8 agents in sequence with the top Scout topic, no interruptions
- **Manual Topic** — enter any topic and launch the pipeline from Radar directly

### Script Editor
- **Inline editing** — click any audio-script cell to edit it in place
- **Undo / Redo** — Ctrl+Z / Ctrl+Y with a 20-snapshot stack
- **Per-block RU translation** — re-translate any individual block without rerunning the Writer
- **RU stale indicator** — highlights blocks where EN was edited after the RU translation was generated
- **Rewrite** — AI pass to eliminate repetitions across the entire script
- **Audit Fix** — AI pass to automatically resolve audit warnings

### Audit Panel
Validates the script against production rules:
- Demonetization keyword detection
- HOOK must be first block, OUTRO must be last
- Exactly 1 SALES block required
- No more than 4 consecutive blocks of the same type
- Estimated duration must be 15–20 minutes
- Short blocks (< 30 words) flagged

### Search & Navigation
- Full-text search across EN audio, RU audio, and visual cues
- Filter by block type (HOOK, INTRO, BODY, TRANSITION, SALES, OUTRO)
- Jump-to-type navigation in paginated view (20 blocks per page)

### SEO Package
Generates a complete YouTube upload kit:
- 5 title variants
- Video description
- Tags string
- Pinned first comment
- End screen script

### Storyboard
- Per-block AI image generation (cinematic, geopolitical thriller style)
- Bulk "Generate All" mode fills all missing frames sequentially
- Thumbnail concept preview generated by the Architect agent

### Export
| Format | Contents | Use Case |
|--------|----------|----------|
| **Dossier (.doc)** | Radar + Analyst + Architect output | Research review |
| **Script (.doc)** | Full timecoded script with optional storyboard images | Production handoff |
| **Script + Images (.zip)** | .doc + all generated storyboard frames | Full production package |
| **Editor Task (.csv)** | Timecodes, visual cues, EN/RU audio columns | Video editor worksheet |

All exports support Cyrillic (UTF-8 with BOM).

### Import
Re-import a previously exported script to continue editing:
- `.json` — raw script block array
- `.csv` — editor task format
- `.doc` / `.docx` — Tech.War HTML export or real DOCX (via Mammoth)

### Topic Templates
15+ pre-defined narrative scaffolds across 6 categories:

| Category | Examples |
|----------|---------|
| Geopolitics | Rise & Fall, Secret Deal, Proxy War, Economic Siege |
| Business | Billion-Dollar Fraud, Monopoly Machine, Asset Bubble |
| History | Government Cover-Up, Forgotten Operation |
| Crime | Criminal Empire, Whistleblower |
| Technology | Tech Race, Surveillance State |
| Society | Cult / Sect, Propaganda Machine |

### Auto-Save & Draft Restore
- Work-in-progress auto-saved to `localStorage` after 1.5 s of inactivity
- On next load, a banner offers to restore or discard the draft

### History
- Every completed pipeline run is saved to Supabase (optional)
- History tab shows all past runs; click any entry to restore its full state
- Individual entries can be deleted

### Settings Panel
- Per-agent model overrides (Flash ↔ Pro)
- Auto-SEO toggle (generate SEO package after Writer completes)
- Show/hide Russian script column
- Parallel act writing mode (faster, bypasses motif tracking)

### TTS Preview
Browser text-to-speech playback of the script, block by block, with adjustable speech rate.

## Python Backend (FastAPI)

The backend (`main.py`) proxies all Gemini API calls so the API key never leaves the server, and provides two RAG endpoints:

| Endpoint | Description |
|----------|-------------|
| `GET /` | Health check |
| `GET /api/prompts` | Serves all agent prompts (update without frontend rebuild) |
| `POST /api/get-harris-style` | ChromaDB: Johnny Harris style examples for the Writer |
| `POST /api/get-screenwriting-principles` | ChromaDB: Tyler Mowery structural principles |
| `POST /api/proxy/*` | Gemini API proxy with retry (3 attempts, 1.5 s exponential backoff) |

### Training Data (ChromaDB)
- `training_data/` — Johnny Harris YouTube transcripts (style, pacing, narration)
- `scripts/ingest_tyler_mowery.py` — Tyler Mowery screenwriting lecture transcripts
- `scripts/style_search.py` — k-NN retrieval for Writer style context
- `scripts/screenwriting_search.py` — k-NN retrieval for structural principles

## Tech Stack

- **Frontend:** React 19, TypeScript 5.8, Tailwind CSS 4, Vite 6
- **Backend:** FastAPI (Python 3.12), ChromaDB, uvicorn

- **Testing:** Vitest 4, Testing Library
- **Linting:** ESLint 10 with `typescript-eslint`

## Getting Started

### Prerequisites

- Node.js >= 20
- Python >= 3.12
- Google Gemini API key ([get one here](https://aistudio.google.com/apikey))
- Supabase project (optional — history persistence)

### Installation

```bash
git clone <repo-url>
cd techwar.sys
npm install --legacy-peer-deps
pip install -r requirements.txt
```

### Configuration

```bash
cp .env.example .env
```

```env
GEMINI_API_KEY=your_gemini_api_key_here
GOOGLE_API_KEY=your_gemini_api_key_here   # used by the Python backend
SUPABASE_URL=your_supabase_url_here
SUPABASE_KEY=your_supabase_anon_key_here
VITE_USE_BACKEND_PROMPTS=false            # set true to load prompts from backend
```

> Supabase is optional. Without it the app works fully but does not persist history between sessions.

### Supabase Setup

Run the migrations in order:

```bash
# 001_init.sql — creates mediawar_history table
# 002_add_project_type.sql — adds project_type column
```

Or apply manually:

```sql
CREATE TABLE mediawar_history (
  id          BIGSERIAL PRIMARY KEY,
  created_at  TIMESTAMPTZ DEFAULT now(),
  topic       TEXT NOT NULL,
  model       TEXT NOT NULL,
  project_type TEXT,
  radar_output      TEXT,
  research_dossier  TEXT,
  structure_map     TEXT,
  thumbnail_concept TEXT,
  script      JSONB NOT NULL
);
```

### Run

```bash
# Terminal 1 — Frontend
npm run dev           # http://localhost:3000

# Terminal 2 — Backend (required for RAG & proxy)
python main.py        # http://localhost:8000
```

### Ingest Training Data (one-time)

```bash
python scripts/ingest_style.py          # Johnny Harris transcripts → ChromaDB
python scripts/ingest_tyler_mowery.py   # Tyler Mowery principles → ChromaDB
```
